Consolidation proposal · interactive architecture

One hub-and-spoke platform, read five ways

The same target architecture as docs/architecture/excalidraw/05-network-topology.excalidraw, rebuilt as five explorable scenes. Nothing here is a new design: the topology, the two databases, the single hub firewall and the corrections carried in from the proposal paper's technical review are unchanged. What changed is that you can now interrogate them.

Each scene is one self-contained HTML file with five guided chapters. Open one and press P to play the chapters in order, or ? for the full list of controls.

What these scenes claim

Nothing in this folder is deployed. Address ranges, sizes and node counts are proposals. The availability and cost figures from the earlier design are withdrawn rather than restated, and the open findings — the retention-versus-erasure position, the recovery-region choice, the missing volumetric basis — are shown as open. Selecting a node reveals only relationships that were actually authored; the viewer never infers a path that is not in the source.
